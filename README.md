# บ้านผัก (Baan Phak)

เว็บร้านผักผลไม้จากสวน: หน้าร้านออนไลน์ · เคาน์เตอร์ (POS) · หลังบ้าน · แดชบอร์ด

- เว็บแบบไฟล์เดียว (`index.html`) ไม่ต้อง build — Vercel ตั้ง Framework เป็น **Other** ได้เลย
- ข้อมูลสินค้า ราคา ออเดอร์ และรูป เก็บที่ Supabase (โปรเจกต์ `baanphak`)
- `app-supabase.js` = ส่วนเชื่อมต่อฐานข้อมูล ถ้าต่อไม่ได้ เว็บจะใช้ข้อมูลสำรองในไฟล์
- ผู้ดูแล: ล็อกอินด้วยอีเมล/รหัสผ่าน (Supabase Auth) และต้องมีชื่ออยู่ในตาราง `admins`
